First, what is this thing?

Not a chatbot.
A colleague with hands.

Three things make Claude Code fundamentally different from any chat window you've used.

01 · Where it lives

In your terminal, inside your folder

Claude Code is a program you install on your own computer. You open it inside a project folder, your folder, your files, and talk to it in plain English. Nothing gets pasted into a website.

02 · What it sees

Your whole project, not one snippet

It reads your files itself, understands how they relate, and remembers the context. You never explain your setup twice or copy data into a chat box.

03 · What it does

It acts, checks, and corrects

It plans, takes an action (reads a file, writes code, runs it), looks at the result, and decides the next step. A chatbot answers. This one works, and catches its own mistakes.

The honest analogy: imagine a skilled colleague pulling a chair up to your desk. You say "merge these 50 files." They don't recite instructions at you. They take the keyboard, do it in front of you, show you exactly what they changed, and ask "does this look right?" before moving on. You manage. It does.

The questions you're actually asking
Do I need to know how to code?
No. You type what you want in plain English, the way you'd brief a colleague. Claude writes any code; you just read the result and approve it.
Do my files get uploaded somewhere?
It runs on your own machine and works on files already on your computer. Your data stays local; it isn't pasted into a website.
Is it expensive?
It runs on a paid Claude plan or API credits, the cost of a normal software subscription, not an enterprise licence. You can start small.
What do I actually need to install?
One free tool called Node.js, then a single install command. On a locked-down work laptop you may need IT to allow it, worth checking first.

        Under the hood · optional depth

        How it really works

        You don't need this section to get value from Claude Code. But if you like knowing the mechanics before trusting a tool, this is the honest version, and you can try it hands-on.

        The session

        Two commands and you're in

        Open a terminal, step into any folder, type claude. That's the whole ritual. From then on you type plain English, and it works on the files around it.

        If the terminal scares you: think of it as a plain text box where you write full sentences, not secret commands. "clean the June export and flag anything unusual" is a perfectly valid thing to type.

        $ cd ~/monthly-reports
        $ claude
        Welcome to Claude Code. Working in ~/monthly-reports
        clean the June export and flag anything unusual
        …and it starts working.
        The memory

        CLAUDE.md, the project briefing

        Run /init once and it scans your project, then writes a plain-text file called CLAUDE.md: what the project is, where things live, your conventions. Every future session reads it first. It's just text, so you can edit it like a note to a new team member.

        # CLAUDE.md
        ## Project
        Monthly sales reporting for 50 branches.
        ## Conventions
        - Dates are DD/MM/YYYY, amounts in KWD
        - Master file: master_sales.xlsx, never edit raw exports
        - Always verify row counts after any merge
        The safety net · interactive

        It edits files as proposals you approve

        Claude Code never silently rewrites your work. Changes appear as a diff: red is what goes, green is what comes. Nothing touches your file until you say so. Try it, this one's live:

        A chat assistant

        • Gives you advice and code to copy-paste
        • Never sees your actual files
        • You run it, you debug it, you retry
        • Forgets your project every session
        • Output: a message

        Claude Code

        • Opens your folder and reads your real files
        • Writes the solution, then runs it itself
        • Catches its own errors and fixes them
        • Remembers your project via CLAUDE.md
        • Output: finished files, reports, working apps
        Your first 10 minutes
        1
        Install it. Install Node.js (free), then run the one command below. Ten minutes, once.
        2
        Pick a harmless folder. Copy a few messy Excel or CSV files into a new folder so nothing important is at risk.
        3

        Give it one real task. "Combine these into one file and remove duplicates." Watch it work, then approve. That's the whole loop.
