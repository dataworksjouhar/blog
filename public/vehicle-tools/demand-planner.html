How the calculation works

In three sentences: when stock is on target, order what you will sell. If you are short, order a bit extra; if you have too much, order less. Because orders take 3 months to arrive, every order is for the month 3 months away.

  1. Each month: closing stock = opening stock + arrivals - sales. Sales use the actual when there is one, otherwise the forecast.
  2. Target stock = enough cars for the next 3 months: target cover x average forecast sales of the next 3 months.
  3. Stock cover = closing stock / average forecast sales of the next 3 months.
  4. An order placed this month arrives one lead time later. Arrivals before that are already fixed by earlier orders.
  5. Order now = what that month sells + what it is short of target stock (less if it has extra, never below zero).
